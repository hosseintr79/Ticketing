# مقدمه: تیکتینگ چیه؟

## تعریف
صندوق پستی هوشمند برای مشکلات مشتری‌ها

## ۴ جزء اصلی
- تیکت (درخواست)
- پیام (گفتگو)
- کاربر (مشتری/پشتیبان)
- وضعیت (باز/بسته)

## اصطلاحات
- Ticket = تیکت
- Agent = پشتیبان
- Customer = مشتری
- Status = وضعیت
- Priority = اولویت
- SLA = قرارداد زمان پاسخ
- Tenant = شرکت مشتری
- SaaS = نرم‌افزار ابری
- Multi-tenant = چند شرکتی

## چرا شرکت‌ها می‌خوان؟
- گم نشدن درخواست‌ها
- رضایت مشتری
- نظم پشتیبان‌ها
- آمار برای مدیر
- کیفیت بهتر
